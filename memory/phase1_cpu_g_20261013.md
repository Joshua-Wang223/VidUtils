## 读数须知

- 墙钟含 Python 启动与模型加载；script_reported_elapsed 不含模型加载且三条执行路径口径不一致，仅供交叉核对。SKIP 不等于通过。
- `crf_sent` 是真正下发给编码器的原生值，不是 `--crf-ref` 的数字：该基准处**没有任何编码器是恒等映射**。
