`convert_sdr_to_hdr.py` 的「音轨比视频短 ⇒ 自动降级为重编码 + `-af apad` 补静音」
已落地（用户拍板）。本条记录**判据的边界与盲区**，改这段判据前必读。

## ⚠ 阈值定1 帧而不是 3 帧（曾用 3 帧放过真实丢帧）

先用 3 帧，理由是「丢 1~2 帧是容器舍入噪声」。实测
`../input_videos/test3.mp4` 音轨短 **0.0597s = 1.79 帧** ⇒ 不触发降级
⇒ 实测**仍丢 3 帧（302→299）且 EXIT=0、零告警** —— 真实丢帧被当成了噪声。

**降到 1 帧的依据（先量噪声幅度，不拍脑袋）**：同源等长素材（lavfi 同时产视频与音频）
ffprobe 报出的两流 duration **完全相等（偏差 0.00 帧）**；等长偏差 0、音轨偏长为负
⇒ 1 帧不会被容器噪声误触发，却能抓住 1.79 帧的真实丢帧。

⚠ **阈值过高的代价是「静默丢帧」，比多一次重编码严重**（后者有告警、
可用 `--audio none` 规避、看起来完全正常）。给容差设值前先拿**一个已知真实缺陷
样本**（哪怕只有一个）确认新阈值仍能抓到它。

## 显式 `--audio-codec copy` 会被覆盖（按能力维度而非值判断）

判「要不要为保帧而重编码」时，必须问「这条音频路径**能不能加滤镜**」
（即是否非流复制），而不是「它是不是 copy」：

- 值（指定了 `libopus`/`aac`）⇒ **尊重不改写**，只在旁边加补救（保留 opus + 只补 apad）。
- 能力开关（指定 `copy`，即「不要重编码」）⇒ **覆盖它**，因为它正是与正确性冲突的点。

⚠ 覆盖显式参数时必须在提示里点明「**你显式指定的 X 同样会被降级**」并给出去路，
否则用户会以为那个参数是能关掉行为的开关。
⚠ 判「用户是否显式指定」**不能用 `sys.argv` 扫全量**：`--extra-args` 之后的参数
是给下游工具的（会被 `_split_extra_args` 切走），扫全量会把
`--extra-args -- --audio-codec copy` 误判成「用户显式指定脚本参数」（实测踩过）。
正确做法：用 argparse 收到的 argv（`validate_args(args, argv)`），
拿不到时保守判 False。

## 分段末段 `seg_dur=None` 的取值坑

`build_plan` 里算 `video_duration` 用的是
`seg_dur if _seg and seg_dur else meta["duration"]`。末段 `seg_dur=None`
时会退回**全片时长** ⇒ 末段的音轨偏短判定用错基准（偏小 ⇒ 可能漏判）。
分段的正确性依赖「每段各自判」，不是首段判一次。

**【已修复】2026-10-10**：改为使用 `_segment_durations(meta, seg_start, seg_dur)`，
返回（本段视频时长, 本段音轨时长），算法是取「本段视频区间 ∩ [0, 全片音轨长]」的交集。
这样既避免了用全片音轨长减本段视频长（两数分属不同区间，差值无意义），
也避免了退回全片时长时的高估误差。实测（4 段、视频 44s）：
  音轨16s 段1[11,22) 真实短 6s，旧口径算11-16=-5 ⇒ 判不短 ⇒ 不补静音 ⇒ BrokenPipe
  音轨30s 段2[22,33) 真实短 3s，旧口径算 11-30=-19 ⇒ 同上失败
  音轨10s 旧口径碰巧算对 ⇒ 侥幸成功（最危险：靠运气）
  末段还有反向问题：seg_dur=None 退回全片时长又会高估（真实短 11s 却报 34s）。
现在统一按「本段视频区间 ∩ [0, 全片音轨长]」算交集，5/5 实测全通过、帧数全 1100 完整；
等长与音轨偏长素材仍零告警（无误触发）。

## 本机基线数字（仅供参照，换机器/素材必须重测）

1080p 单帧 CPU 推理约 **10~24 秒**（与负载相关）；4K 整帧 237.7s / tile1024 89s。
音轨偏短的两类典型素材：视频 22s/550帧 + 音轨 5s（短 17s）、真实素材 test3.mp4（短 1.79 帧）。

**【2026-10-10 本次会话验证】** _segment_durations() 修复段音频基准生效：5/5分段音频矩阵全通过、帧数全 1100 完整，等长/偏长素材零误触发。旧口径「全片音轨长减全片视频长」在分段场景下会产生无意义差值，导致 3/5 条整条 BrokenPipe 失败；新口径「本段视频区间 ∩ [0, 全片音轨长]」交集消除此类误判。
