派 Explore/子 agent 做审计后，**它们的结论本身也要复核**，不能因为「有 agent 背书」
就直接写进 commit message、归档清单或记忆。已踩过多次：

## ① 子 agent 报「文件不存在」可能是它只看了一个目录

GPU 待测项审计的 agent 断言 7 个 memory 文件不存在。实际原因：**仓库内 `memory/`
（git 跟踪）与 agent 私有目录 `~/.codebuddy/.../memory/` 两套并存**，它只看了后者。
⇒ agent 说「找不到」时，先自己 `ls` 再决定信不信。

## ② 子 agent 与我自己的实测数字都可能指向错的文件

- agent 纠正我「vmaf.json 内嵌 ffmpeg 戳」时，它自己的结论里也把
  `version: 2.3.1`（libvmaf 的）说成了 ffmpeg 戳 ⇒ **两边都错**（戳在 `report.json`）。
- 我自己在 `archive_manifest.md` 写的「画面均值 0.51」复核实测是 **0.49**；
  「grep 零命中」实际命中 8 处、全在清单文件自己。

⇒ 复核要落到「跑一条命令看输出」，不是「读 agent 的转述」。

## ③ 反向也要验：agent 说的可能对、我的 `ls` 才是错的

我曾断言「模型仓库是空克隆」，agent 报「仓库完整」；复核发现**agent 是对的**，
错因是我 `ls | head -5` 截断了输出。

⇒ 复核时**两边都要落到不带截断的命令**。且当我的结论会导致「某能力不可用」
这类影响设计走向的判断时，**必须单独再验一次**。

## ④ verifier 会夸大严重度、引用不存在的字段

28 条发现里 verifier 亲自驳回了若干条；夸大的有：引用脚本里**不存在的字段**
（`need_crf_ref`）、**行号漂移 76 行**（引用的原文却逐字正确 ⇒ 快照过期）、
严重度偏高一档、把「我实测的数字」当成可复现证据（而那些数字**没落盘产物**）。

⇒ 用**结构化 schema** 收发现（每条带 `evidence`/`trigger`），
拿回后按严重度抽读 top 3，**优先复核「要照着改代码」的那些**（行号自己
`sed -n 'Np'` 验、字段 `grep -c` 确认）。发现里的实测数字要问「产物在哪」。

## ⑤ 长跑 workflow 可能整个返回 `null`——那不是「没问题」

审查 workflow 跑 2h29m 后返回 `[null, null, null]`（三个 verifier 全空，23~29 分钟
的实测白做），另一次跑 5h14m 后输出文件已不可取用。

**最危险的解读是「没报问题 = 没问题」**：null 的真实含义是 agent 死了/没写回结论，
与「审出零发现」在输出里**完全一样**。

⇒ `agent()` 返回 null 时，报告里必须写「该维度未产出结论」，**不许**表述为
「未发现问题」；需要覆盖就重跑该维度（换小范围、别再堆并发）。
⇒ 别把关键事实**押在**长跑 workflow 上：能用一条命令在几分钟内验的事实就自己验。
本次两个 workflow 都没能在需要时给出结论，而我**并行自己实测**（`-shortest` 四个
修法各跑一遍、duration 取值逐素材对比、互斥五种情形逐一测）反而拿到了全部可用结论。
⇒ 等它时**别空等**，去做那些它不覆盖的独立验证。

## ⚠ ⑥ 长跑 workflow 期间 agent 私有 memory 目录被清空（2026-10-09 实测）

一个跑了 **58 分钟仍未结束**的审查 workflow 期间，
`~/.codebuddy/.../memory/` 目录从约 25 个文件变成 **6 个**，`MEMORY.md`
甚至出现「`find` 能列出但 `ls`/`wc` 报 No such file」的不一致状态。
**这不是我做的操作**（我同期只新增了 2 个文件）。

**Why:** 不知道是 workflow、它的子 agent、还是清理逻辑在重写该目录；
在原因不明时批量重建 memory 文件，可能正好覆盖掉某个进程即将写回的内容。

**How to apply:**
- 发现 memory 目录异常减少时，**先报告给用户、不要擅自重建** ——
  重建可能与正在写回的进程冲突。
- 重要的工程结论应**同时**写到仓库内 `memory/`（git 跟踪、有历史），
  不要只依赖 agent 私有目录。
- 长跑 workflow 与 memory 写入**不要并发**：本次丢的是索引文件
  （`MEMORY.md`），它一丢，后续所有对话都失去记忆索引。
