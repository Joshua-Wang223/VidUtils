## 1. 方法（相对 SDR 直编口径的三处修正）

| 要素 | SDR 直编（eqq_calib） | **本次（HDR 管线）** |
|---|---|---|
| 锚 | 原始 SDR 素材 | **HDR 母版**＝模型输出的无压缩帧（gbrp16le → libx265 `-qp 0` 无损） |
| 度量 | VMAF（tonemap 后） | **HDR 10bit PQ 域 PSNR 直比，不做 tonemap** |
| 目标锚值 | x264 crf 整数 | libx265 在 crf-ref 下**实际下发值**（`1.0979·ref−2.3119`，ref21→20.744，**非恒等映射**） |

两个关键工程发现（已实测验证）：
1. **曲线复用**：`PSNR(codec, value)` 曲线与锚点无关（编码器在母版上的固有性质）⇒ 换锚点只需重测目标。
   10 素材 × 5 锚点只用了 50 条 x265 目标编码；曲线复用于 3 素材实测交叉验证 **Δ≤0.5 单位**
   （doc_grassland svtav1 Δ+0.04 / aom Δ+0.47；molly01 svtav1 Δ+0.02 / aom Δ+0.06 / rav1e Δ−0.52 等）。
2. **SVT-AV1 近无损凹陷**（异常，非测量误差）：最低 crf（4 或 8）在 3/10 素材上 PSNR 反而低于次低点
   （码率更大、PSNR 更低，可复现）。已在分析中**单调化剔除**并留档：
   wordworld crf4=49.742 / subs crf8=46.710 / screen_ui crf4=55.698。

素材＝`eqq_calib/6s` 全 10 条（6 类内容全覆盖：3D 动画 ×3、实拍纪录片 ×2（含 4K）、实拍 ×3、屏幕 UI ×1、剧集 ×3，其中 4K 用 10 帧、其余 20 帧）。

## 4. 精度与离散度

- **逐锚点 IQR**（跨 10 素材）：svtav1 3.3~7.1 ｜ aom 3.8~7.5 ｜ rav1e 10.1~18.5（qp 轴 0~255）。
- **仿射残差**（全点）：svtav1 中位 2.0 / max 8.8（≈ 中位 0.50 / max 2.98 dB）；aom 中位 1.9 / max 6.3（0.52 / 1.70 dB）；rav1e 中位 7.2 / max 30.0（0.64 / 4.47 dB）。
- **LOO（逐素材留一）** dB 当量：svtav1 中位 0.56 / P90 1.76 / max 3.20；aom 0.66 / 1.51 / 1.90；rav1e 0.78 / 2.46 / 4.78。
- 结构上限（同 VE 侧结论）：`(a,b)` 单行仿射 + 反查存在跨素材上限；rav1e 的 qp 轴相对映射太粗（IQR 达轴长 7%）。

## 5. 与 `eqq_calib` SDR 直编口径的关系（重要）

- 两者**不同域、不可互相替代**：SDR 直编（VMAF 匹配、素材为锚）方法学正确，**不受本结论影响**；
  本结论只回答「SDR→HDR 管线**在 HDR 域**下，AV1 三兄弟与 libx265 的等质量点在哪」。
- C8 已证：该管线上 VMAF（tonemap 后）无判据分辨率（斜率 −0.013）；HDR 域 PSNR 有（+0.190）。本标定即按后者。
- ⚠ PSNR 非感知指标；本表是**当前工具下最优的客观锚**，若未来有 HDR 域感知指标（如 vmaf_hdr）应复标。

## 9. svtav1 分段升级（2026-10-16，已落表；§6 末条 / §8 遗留 (b) 的裁定）

**动机**：逐锚点中位曲线轻微非线性（相邻锚点差分 11.8 / 9.0 / 8.7 / 8.7 crf），
单条仿射无法同时贴近全部锚点。

**候选与 LOO**（逐素材留一；真值 = 各素材曲线上的等 PSNR 交点；dB 当量 = |Δqp|×局部斜率；
三类评价网格：锚点 5 点 / 整数 18..30 / 0.5 步 25 点。写法「中位 → 最坏」）：

| 模型 | 锚点 qp | 整数 qp | 密集 qp | 密集 dB |
|---|---|---|---|---|
| 仿射（旧表） | 2.31 → 8.98 | 2.34 → 9.19 | 2.34 → 9.22 | 0.50 → 3.43 |
| 分段·中位值连线 | **1.84** → 10.62 | 2.13 → 10.62 | 2.12 → 10.72 | 0.43 → 3.78 |
| **分段·稳健增量累积（采纳）** | 2.05 → **9.00** | 1.96 → 9.16 | **1.92** → 9.22 | **0.40 → 3.33** |
| 两段 LSQ（断点 21 / 22.5） | 2.26 → 10.18 | 2.25 → 12.02 | 2.25 → 12.24 | 0.47 → 3.70 |
| 二次回归 | 2.11 → 10.25 | 2.19 → 10.79 | 2.27 → 10.79 | 0.51 → 3.77 |

- 最坏点全部由同一批水平离群素材主导（kids_play 全程低 5~10 qp、molly_s01/s03 全程高
  5~7 qp）；模型差异只是误差在这些素材上的再分配——跨素材 IQR（3.3~7.1 qp）才是误差主项。
- 「中位值连线」中枢最优但最坏点劣化 +1.6 qp（kids_play 被推得更远）⇒ 与「首先保质量不退」
  冲突，不采纳。
- 「稳健增量累积」= 从 ref18 中位值出发、逐段累加**素材内增量中位数**（Theil–Sen 式），
  对全程水平离群不敏感 ⇒ 中枢优于仿射、最坏点持平（唯整数网格 qp-P90 +0.10，噪声级）。

**采纳节点**（4 位落表 = `_HDR_SVTAV1_KNOTS`；全精度见 json `.codecs.libsvtav1.piecewise.knots_cuminc`）：
`18→12.5065 / 21→22.7691 / 24→32.9637 / 27→43.0370 / 30→50.7369`
（逐段斜率 3.4208 / 3.3982 / 3.3578 / 2.5666 crf；首/末段斜率外推、钳 [0,63]）。
⚠ 与 `.per_ref_median`（…/ 24.2997 / … / 42.0414 / …）**刻意不同**——两者是同一中位曲线的
不同估计量，LOO 显示稳健累积更优（此处留痕防审计困惑）。

**下发变化**（整数 ref，`int(round())`）：@21 仍 **23**（方案 C 对外口径不变）、@30 **52→51**；
23/26/27 各 +1、28 持平、29/30 −1；31~33 因末段斜率较缓（2.5666 vs 3.2689）相差 2~4。
ref<18 走首段外推（@15→2 qp），**未实测** —— 见 §10 建议 1。

`convert_sdr_to_hdr.py` 静态量程回退改 `row_limits()`。aom / rav1e 维持仿射（LOO 无一致增益：
aom 分段中枢退化、rav1e 最坏点不降）。
**回归**：`verify_quality_mapping.py` [12]（节点逐点 / 插值 / 外推 / 钳位 / 反解 / 量程 /

## 10. 精度追加选项分析（2026-10-16，待定——供决策）

前提：跨素材离散（IQR 3.3~7.1 qp ≈ 1.5~3 dB）是误差主项；下列追加项都只可能改善二阶项，
按「先便宜后昂贵」排序：

1. **加 ref15 锚点（推荐，先做；≈1~2 h）**。动机：分段在 ref<18 走首段斜率外推（未实测），
   而 15~18 是 HDR 交付常用档。成本低于原估——**曲线复用**（§1）⇒ 只需 10 条 x265 目标编码
   + 低端补扫。实测覆盖检查（t15 为线性外推的指示值）：svtav1 **7/10 素材**超出现曲线最高点
   （需补 qp≲4~12 的点，注意近无损凹陷口径不变）、aom **0/10**、rav1e **1/10**（screen_ui <24）。
2. **拉长片段差分校验（推荐，小范围；≈0.5~1 h）**。现状每条仅前 20 帧（4K 10 帧）；风险 =
   短切片上「svtav1 vs x265」的差分 PSNR 有偏移 ⇒ 等质量点整体平移。做法：抽 3 条素材
   （避开 4K）在 ref21 等质量 qp 附近各补 1~2 条**全长**编码（≈7.5× 帧数），比「全长 vs 20 帧」
   的 ΔPSNR(codec−x265)：|Δ|≤0.3 dB ⇒ 20 帧代理无偏、闭环；>0.3 dB ⇒ 扩大范围重估。
3. **换 10s 素材集复标（不推荐单独做）**。`eqq_calib` 的 5×10s 是**不同内容切片**——换池子
   会把「时长」与「内容」两个变化混在一起，且会作废现落表值。若预算允许，更值的用法是
   **扩池**（10→15 条，含 10s）重估节点、直接缩小 LOO 折间抖动；但当前 LOO 已持平/优于仿射、
   这类追加边际收益低，建议等前两项结果出来后再定。
