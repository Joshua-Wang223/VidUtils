## 1. 方法（相对 SDR 直编口径的三处修正）

| 要素 | SDR 直编（eqq_calib） | **本次（HDR 管线）** |
|---|---|---|
| 锚 | 原始 SDR 素材 | **HDR 母版**＝模型输出的无压缩帧（gbrp16le → libx265 `-qp 0` 无损） |
| 度量 | VMAF（tonemap 后） | **HDR 10bit PQ 域 PSNR 直比，不做 tonemap** |
| 目标锚值 | x264 crf 整数 | libx265 在 crf-ref 下**实际下发值**（`1.0979·ref−2.3119`，ref21→20.744，**非恒等映射**） |

两个关键工程发现（已实测验证）：
1. **曲线复用**：`PSNR(codec, value)` 曲线与锚点无关（编码器在母版上的固有性质）⇒ 换锚点只需重测目标。
   10 素材 × 5 锚点只用了 50 条 x265 目标编码；曲线复用于 3 素材实测交叉验证 **Δ≤0.5 单位**
   （doc_grassland svtav1 Δ+0.04 / aom Δ+0.47；molly01 svtav1 Δ+0.02 / aom Δ+0.06 / rav1e Δ−0.52 等）。
2. **SVT-AV1 近无损凹陷**（异常，非测量误差）：最低 crf（4 或 8）在 3/10 素材上 PSNR 反而低于次低点
   （码率更大、PSNR 更低，可复现）。已在分析中**单调化剔除**并留档：
   wordworld crf4=49.742 / subs crf8=46.710 / screen_ui crf4=55.698。

素材＝`eqq_calib/6s` 全 10 条（6 类内容全覆盖：3D 动画 ×3、实拍纪录片 ×2（含 4K）、实拍 ×3、屏幕 UI ×1、剧集 ×3，其中 4K 用 10 帧、其余 20 帧）。

## 5. 与 `eqq_calib` SDR 直编口径的关系（重要）

- 两者**不同域、不可互相替代**：SDR 直编（VMAF 匹配、素材为锚）方法学正确，**不受本结论影响**；
  本结论只回答「SDR→HDR 管线**在 HDR 域**下，AV1 三兄弟与 libx265 的等质量点在哪」。
- C8 已证：该管线上 VMAF（tonemap 后）无判据分辨率（斜率 −0.013）；HDR 域 PSNR 有（+0.190）。本标定即按后者。
- ⚠ PSNR 非感知指标；本表是**当前工具下最优的客观锚**，若未来有 HDR 域感知指标（如 vmaf_hdr）应复标。

### 10.2 选项 2：拉长片段差分校验（✅ 执行记录见节末：3 PASS / 4 FAIL → 需重估）

背景：现状每条仅前 20 帧（4K 10 帧）；风险 = 短切片上「codec vs x265」的差分 PSNR 有偏移
⇒ 等质量点整体平移。做法：抽 3 条素材（避开 4K）在 ref21 等质量点各补**全长**编码
（≈7.5× 帧数），比「全长 vs 20 帧」的 ΔPSNR(codec−x265)：|Δ|≤0.3 dB ⇒ 20 帧代理无偏、闭环；
>0.3 dB ⇒ 扩大范围重估。

**执行记录（2026-10-16/17，CPU 真模型推理；7 素材 / 14 点）**：

- 协议：全长母版 = 模型全帧推理（agcm、gbrp16le 720p）；无损锚 = libx265 -qp 0；
  目标 = libx265 crf_sent 20.744 全长；svtav1 取 20 帧曲线跨 v21 的两个实测点全长编码；
  度量 = psnr 滤镜（10bit、不 tonemap，summary = 合并 MSE 口径）；diff = Δfull − Δ20，判据 |diff| ≤ 0.3 dB。
  先验 3 素材（wordworld / subs / kids_seated），按「>0.3 dB ⇒ 扩大范围」追加 4 素材

- 完整性：7 素材的 20 帧标定母版与全长母版前 20 帧**字节一致**（模型逐帧无状态——

    x265 短编码自身吃亏 +0.24~+0.74 dB（14/14 全为正，均值 +0.45）、svtav1 位移正负不一

  · 主导项：kids_seated / molly 由 ctx 主导；screen_ui / grassland 由 fset 主导；PASS 三条为两效应相消。
- 范围注记：本校验覆盖 **svtav1 行**（主码器）；aom / rav1e / vp9 行的时长译移**未测**
  （同方法论 ⇒ 风险同源；B 立项时一并重测）。

  以负偏为主（均值 −0.47）⇒ 现落表值在「等质量」意义上需**重估**。

**重估路径（决策项）**：
- A. 维持现表 + 本记录留痕：成本 0；live / TV / screen 类素材或有 ~1~1.7 dB 兑现偏差（负偏）。
- B.（推荐）**全长重标定**：10 素材全长母版重跑 eqq 标定（3 码器全网格 + 锚）→ 重拟合节点
  （`_final_fit.py` / `loo_equal_quality.py` 链）→ 既有「钉值双绿 + 文档/矩阵同步」流程。
  可见收益：直接消除 ctx（本次最大系统性来源，均值 −0.66、最坏 −1.63）；成本：编码量 ×8~10
  （数小时级后台 CPU，可并行）。
- C. 其余 3 素材（talking_tom / dark_earth / molly_s03e01）补齐全长校验（证据扩至 10/10）：
  非终局选项（做完仍回 A/B）；B 实施时其全长母版被直接复用。
- **裁定（2026-10-17）**：**C + B** —— 先执行 C（3 素材补测 → 10/10），随后进入 B 全长重标定。
